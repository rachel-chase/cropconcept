# CropConcept ABC tasks

Task tracker for the CropConcept ABC project. The list lives in `tasks.csv`.

## Columns

| Column | What to enter |
|---|---|
| Activity | The broader work package or activity the task belongs to |
| Task | What needs doing |
| Person | Who is responsible |
| Deadline | Date as YYYY-MM-DD, for example 2026-10-15 |
| Completed | Yes or No |

## Editing

- Edit on GitHub (pencil icon on `tasks.csv`) or ask Claude to update it.
- Put text containing a comma in double quotes, for example `"Seed, fertiliser"`.
- Avoid opening and saving the file in Excel. Excel can change date formats and accented characters.
- Row 2 is an example. Replace or delete it.

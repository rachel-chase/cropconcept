# CropConcept ABC tasks

Task tracker for the CropConcept ABC project. The list lives in `tasks.csv`.

## Columns

| Column | What to enter |
|---|---|
| Activity | Activity number from the workplan, for example 1.2.3 |
| Task | What needs doing |
| Person | Who is responsible |
| Update | Short note on the latest progress |
| Update date | Date of that update, as YYYY-MM-DD (for example 2026-10-15) |
| Output | What the task produced, for example a brief, dataset or link |
| Completed date | Date the task was finished, as YYYY-MM-DD. Leave empty while the task is open |

## Editing

- Edit on GitHub (pencil icon on `tasks.csv`) or ask Claude to update it.
- Every row needs the same number of commas as the header (six). Leave a field empty rather than deleting its comma.
- Put text containing a comma in double quotes, for example `"Seed, fertiliser"`.
- Avoid opening and saving the file in Excel. Excel can change date formats and accented characters.
